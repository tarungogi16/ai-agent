Inside the Agentic AI Multi-Agent Loop

RFID telemetry alone is static. The 4 autonomous agents below actively reason, predict availability, synthesize slot trade-offs, and autonomously escalate unhandled student requests.

01

NL Intake Agent

Ingests unstructured speech/text queries. Extracts semantic intent, entity matching, and priority weight.

Accuracy: 96.4% Latency: ~220ms
02

Availability-Prediction Agent

Blends real-time door tap dwell decay, room type, and recurring timetable to calculate presence probability.

Decay Model: Exponential Signals: RFID + Routine
03

Meeting-Negotiation Agent

Synthesizes 2-3 optimal meeting slots with multi-factor reasoning (inter-block transit, queues, office hours).

Buffer: 15m inter-block Conflict: Zero overlap
04

Autonomous Escalation Agent

Autonomous watchdog daemon. Re-routes requests when professors leave campus, assigns TAs, or priority-reschedules.

Poll Rate: 45s background Failover: Multi-Tiered
